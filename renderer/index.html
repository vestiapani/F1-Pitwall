PANDUAN KONEKSI F1 PITWALL

KONEKSI VIA WIFI

  • Pastikan PC dan HP terhubung di jaringan WiFi yang sama.
  • Pilih mode WiFi di navbar.
  • Masukkan IP Server yang tertera di layar PC ke aplikasi HP.
  • Troubleshoot: Jika tidak mau konek, pastikan Port 3000 tidak diblokir oleh Windows Defender Firewall (Inbound Rules).

KONEKSI VIA USB (ADB)

  • Aktifkan USB Debugging di Developer Options HP.
  • Colok HP ke PC menggunakan kabel data USB.
  • Klik tombol USB di navbar aplikasi PC ini. Tunggu sampai notifikasi ADB sukses.
  • Di aplikasi HP, isi IP dengan 127.0.0.1 atau biarkan HP terhubung otomatis melalui localhost.
